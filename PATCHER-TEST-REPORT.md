# Проверка DLSSG Patcher — 12 сентября 2026

Готовый `DLSSG-Patcher.exe` находится в корне проекта. Размер: 73 589 624 байта. SHA256: `e7a78de77d878a91318b284eca2c3a1bad250acb1c853dcb6704de03ca85b1ca`.

## Подтверждено

- 65 автоматических тестов прошли: установка, повторная установка, обновление, откат, удаление, сохранность чужих файлов и настроек, повреждения и прерывания операций, ограничения записи, блокировки и интерфейс.
- Собранный EXE запускается из корня и отдельной папки с кириллицей и пробелами при исключённом Python из окружения. Отдельная физическая машина без Python не использовалась.
- Пять прокси встроены в каталог ресурсов. В процесс патчера загружаются только системные одноимённые DLL; мод из корня проекта в патчер не загружается.
- Проверены живой запрос GitHub и полное скачивание зафиксированного комплекта с проверкой структуры, Git blob SHA1 и SHA256. DLL совпали с встроенной версией; отличие THIRD_PARTY_NOTICES.txt ограничено окончаниями строк.
- На настоящей Bodycam проверен откат: добавленные DLL и INI удалились, 10 штатных файлов NVIDIA/Streamline сохранились без изменений.
- Затем финальный EXE повторно установил Native 0.2.4, ревизия `5f62ff44a9c08f9841fa605e7b7160f79ccd2c40`, рядом с `Bodycam-Win64-Shipping.exe` через `version.dll`.
- Bodycam build 25228199 запустилась с изображением. В процессе обнаружена установленная DLL; свежий журнал PID 8816 содержит `configuration` с `native_pipeline` и `ngx_driver_connected`. Проверка патчера возвращает `loaded`. Контрольные суммы 10 штатных файлов совпадают с исходными.

## Текущее состояние и предел проверки

Мод оставлен установленным, диагностика включена. Игра закрыта после проверки. Записи установки, резервные копии и журнал находятся в `patcher-data`; сохраняйте эту папку для отката.

Активная DLSS Frame Generation, прирост FPS, отсутствие артефактов и длительная стабильность **не подтверждены**. В сохранённых настройках Bodycam выбрана генерация AMD FSR и масштабирование NVIDIA DLSS. Escape и Tab не открыли настройки в проверочном запуске. Файлы сохранения не менялись. Следующий игровой тест: выбрать DLSS Frame Generation и начать с 2X; только после проверки изображения отметить результат в патчере. Профиль остаётся экспериментальным.
