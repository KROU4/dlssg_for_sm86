# DLSSG Patcher

Переносной Windows x64 EXE для установки `sdli1995/dlssg_for_sm86`. Первая целевая система — RTX 3060 Ti; первый профиль — Bodycam. Для запуска не нужны Python, CUDA Toolkit или установка самого патчера.

## Начало работы

1. Закройте игру и откройте `DLSSG-Patcher.exe` в корне проекта.
2. Bodycam выбирается автоматически из Steam. Для другой игры укажите папку или игровой EXE; если кандидатов несколько, выберите настоящий EXE рендеринга.
3. Нажмите «Установить». Патчер сохранит исходное состояние и установит одну DLL и `dlssg_sm86.ini`. Штатные NVIDIA/Streamline DLL игры остаются на месте.
4. Запустите игру. В её настройках выберите DLSS Frame Generation; для первого теста используйте 2X. Ограничение «До 4X» в патчере само по себе не включает 4X в игре.
5. Нажмите «Проверить»: свежий журнал подтверждает загрузку мода, а не качество генерации кадров. После игрового эпизода без артефактов можно отдельно отметить «Изображение проверено».

Bodycam — экспериментальный профиль. Патчер не обещает поддержку любой игры и не обходит защиту игры. Актуальный мод работает с DirectX 12 и существующей интеграцией DLSS Frame Generation. Состояние после обновления игры нужно проверить заново.

## Обновления и восстановление

При открытии проверяется GitHub. Новая ревизия загружается целиком в кэш; к игре применяется только кнопкой «Обновить». Если сеть недоступна, встроенный Native 0.2.4 или ранее проверенный кэш остаются доступны. Сам EXE автоматически не обновляется.

«Откатить» возвращает состояние перед последним изменением. «Удалить» восстанавливает состояние до первой установки. Все такие действия требуют закрытой игры. Чужие DLL не перезаписываются. Если установленные файлы были изменены вручную, патчер останавливает изменение и указывает причину; он не угадывает, какую версию следует уничтожить.

Папка `patcher-data` рядом с EXE содержит записи установок, резервные копии и кэш. Сохраняйте её, пока мод используется. При переносе программы после установки переносите и эту папку: другой экземпляр без истории не должен управлять исходными резервными копиями.

Профиль по умолчанию: SM86 / PTX, точная обработка, предел до 4X. Приближённый режим может менять изображение и не гарантирует ускорения. Диагностика на первой установке включена; после проверки её можно выключить и сохранить настройки при закрытой игре.

## Исходники и сборка

`patcher.py` — запуск и диагностический CLI; `patcher_app` — интерфейс, установка, Steam/Windows и обновления. `tests` содержит тесты, которые используют временные папки и не устанавливают мод в игры.

```powershell
python -m unittest discover -s tests -v
.\build_patcher.ps1
```

Сборка использует версии из `requirements-patcher.txt`, уже установленные на этом ПК. Результат — EXE в корне проекта. `verify_patcher.py` проверяет архив EXE и два запуска: из корня рядом с оригинальной DLL и из отдельной папки с кириллицей, без Python в PATH. Отчёты и снимки интерфейса сохраняются в `test-artifacts`.

DLL мода добавляются в архив после анализа зависимостей PyInstaller. Это исключает их ошибочное включение в зависимости самого патчера; дополнительная проверка запуска требует системные версии DLL в процессе приложения.

Диагностический CLI (доступен и у EXE):

```powershell
.\DLSSG-Patcher.exe --action inspect --game 'G:\SteamLibrary\steamapps\common\Bodycam\Bodycam\Binaries\Win64\Bodycam-Win64-Shipping.exe' --report inspection.json
.\DLSSG-Patcher.exe --self-test --no-network --report self-test.json
```

CLI-операции `install`, `update`, `configure`, `rollback`, `uninstall` изменяют выбранную игру; `inspect` и `check` не меняют её DLL/INI. Код завершения ненулевой при ошибке операции.
